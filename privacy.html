Privacy Policy – Whoop Weekly Coach

Whoop Weekly Coach is a personal, single-user application built for private use. It is not distributed to the public and does not serve any third party.

What data is accessed

The app connects to the WHOOP API (v2) via OAuth 2.0 to read the authenticated user's own recovery, sleep, cycle (strain), workout, profile and body measurement data, strictly for that same user's own personal use.

Where data is stored

All data retrieved from the WHOOP API, together with any data entered directly into the app (daily check-ins, goals, uploaded WHOOP data exports), is stored locally in a private database operated by and accessible only to the app's single user. No data is transmitted to or shared with any third party, sold, or used for advertising.

External processing

Computed, de-identified summary metrics (no raw WHOOP records) may be sent to the Anthropic Claude API solely to generate the user's own weekly review text. This is the same single user's own data, processed for their own benefit only.

Data retention and deletion

Data is retained for as long as the user operates the app and can be deleted at any time by the user, who has direct access to the underlying local storage.

Contact

This app has no public support channel, as it is not distributed beyond its single operator/user.
